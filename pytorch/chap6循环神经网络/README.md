## 实验条件

上篇要求网络读完整个序列后预测前两个数字的和，训练/验证/测试为300/500/500条，嵌入和隐状态为32维，训练200回合。默认先做长度10、种子0的对照，最后可开启36组重复实验。

下篇默认从IMDB抽取5,000/1,000/1,000条，使用64维表示，最长128个词元，训练5回合。训练与预测使用相同的分词、词表、未知词和截断规则；第8章在这一基线上比较注意力汇聚。

## 实现要点

- 手写SRN参数映射到 `nn.RNN` 时检查矩阵转置；LSTM还需检查门顺序和两份偏置。
- 梯度截断放在 `backward()` 之后、优化器更新之前，用于控制梯度范数。
- 变长序列先截断再补齐；`pack_padded_sequence` 接收CPU上的长度，跳过补齐位置。汇聚时同样排除补齐部分。
- 双向LSTM使用整段影评中的前后文，适用于全文已可见的分类场景；不要将该输入条件套到在线预测。
- 验证集用于选择模型，测试集用于最终评价；不能用训练准确率替代泛化表现。
